7. Implementation Decisions (Resolved)
All design decisions have been finalised. The table below records how each previously open question was resolved in the final implementation.

Area	Decision Made	Details
System Architecture	Python / FastAPI backend; C++ pybind11 engine; SvelteKit frontend	Three-tier: browser ↔ FastAPI (port 8000) ↔ C++ shared library (.so via pybind11)
Database Schema	PostgreSQL 16 + TimescaleDB extension	Tables: counterparties, portfolios, derivatives, simulation_runs, risk_metrics, margin_calls, sim_presets, audit_log, users, price_history (TimescaleDB hypertable)
Authentication	JWT (HS256); three roles: ADMIN, RISK_MANAGER, AUDITOR	Login via username/password (form-encoded); 8-hour token expiry; role checked per endpoint
API Spec	35 REST endpoints + 1 WebSocket (/ws/simulate)	Base path /api/v1/; WebSocket streams progress events then final RiskMetrics JSON
Deployment	Local demo; uv for Python deps; Vite dev server for frontend	Backend: uv run uvicorn server.main:app; Frontend: npm run dev (port 5173)
